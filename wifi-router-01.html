WiFi Router #1

Recently, we purchased a certain WiFi Router which was certifed by a certification program claiming "fixed-time". It costs more than 200USD, so it should be categorized as not "entry-level". After setting up the WiFi Router, we found the following code fragment: 

const p = 89894891;
const g = 2;
const clientPrivateKey = Math.floor(Math.random() * 1000);
let clientPublicKey = modPow(g, clientPrivateKey, p);
It is really suprising that the private key is generated using Math.random, and such implementation is certified!
